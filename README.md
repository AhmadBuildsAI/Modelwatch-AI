# 🛰️ ModelWatch AI — AI Model Monitoring & Drift Detection

A production-grade MLOps platform that monitors deployed ML models for data drift, prediction drift, data quality issues, and performance decay — with a composite health score and retraining recommendation.

## 🎯 Features

- **Model Registry** — track models and versions (production / testing / archived)
- **Data Drift Detection** — PSI, KS test, JS divergence per feature
- **Prediction Drift** — compare prediction distributions over time
- **Data Quality** — null rates, outliers, range violations, unexpected categories
- **Performance Monitoring** — simulated accuracy/F1/AUC over time
- **Composite Health Score** — single 0-100 metric across all signals
- **Retraining Recommendation** — with reasons and suggested action
- **Automated Alerts** — severity-ranked, acknowledged/unacknowledged
- **Model Comparison** — side-by-side version comparison
